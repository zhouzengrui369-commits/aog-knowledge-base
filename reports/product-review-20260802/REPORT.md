### P0-7: 业务术语错误 — "海航（首都航）"

### P0-8: 航司互援数据 P0 错误

**位置**: `/airlines`
**证据**: `evidence/04-航司互援-数据准确性.md`

- **HU 海南航空** = `010-57817323`
- **JD 首都航空** = `010-57817323` ← **同一个电话！**

AOG 工程师拨错电话 → 联系错航司 AOG desk → 延误。

### P0-9: 联盟归属过期

- HO 吉祥航空 标注 `星空联盟（战略合作）` — 实际 2024 已正式转 **寰宇一家** (oneworld)
- HU 海南航空 标注 `无联盟` — 2018 破产重组后状态模糊

联盟决定 OAL 互援优先级，**信息过期会直接错失互援窗口**。

### P0-10: AuthGate 路由切换掉登录（用户体验灾难）

**位置**: `components/auth-gate.tsx` + browser hard reload
**证据**: 实操过程

每次 `navigate` 触发 hard reload → AuthGate mount → fetch /api/auth/verify → 失败 → 清 token → 显示登录页。

AOG 工程师场景：点 PKX → 输密码 → 点上海浦东 → 又要输密码 → 输 → 跳上海浦东 → 又要输密码……  
**任何一个外行用户会觉得这个系统"老是要登录"**。

### P0-11: UNVERIFIED 状态仍展示具体数据

**位置**: 城市详情顶部
**证据**: 实操 PKX 页

```
数据可信度: ⏳ UNVERIFIED · 待审核
⚠️ PII: confidential
来源: 02_外战预案/B-北京大兴.docx
最后更新: 2026-06-16
```

但 UNVERIFIED 状态下：
- 显示 `021-22379771` 真实电话
- 显示 `aog-desk@ceair.com` 真实邮箱
- 显示 `B787/A320/A321` 执飞
- 显示 "24H 应急响应 ≤ 30min 反馈"

**UNVERIFIED 应该是"不要信我"信号，但 UI 用 UNVERIFIED 标签 + 又展示完整数据 = 矛盾**。  
真实风险：AOG 工程师以为是 VERIFIED 拿去用了。

### P0-12: 城市详情 SLA 承诺无主语

**位置**: 城市详情页

```
24H 应急响应
≤ 30min 反馈
收到 AOG 通知后 30 分钟内首次反馈，4 小时内出保障方案
```

- 30 min 反馈是承诺还是历史平均？  
- 4 小时出方案是 SLA 还是建议？

→ 在 AOG 法律责任敏感的语境下，**没有承诺方的 SLA 文本 = 误导**。
