# AOG 知识库 · 标签体系

> 全局 tag 字典 — 给每个文件打 2-5 个标签
> 命名规则：`#类别/细分`  — 例 `#业务/AOG预案`、`#主题/航材`、`#来源/ima`
> 最后更新：2026-06-16

---

## 一级类别（必选 1 个）

| Tag | 含义 | 适用范围 |
|-----|------|---------|
| `#业务/AOG预案` | AOG 应急保障预案 | 检查单、预案、航材手册 |
| `#业务/外战` | 外战（外站/境外）保障 | 外战保障预案/220 个 docx |
| `#业务/航材` | 航材管理 / 供应链 | 航材手册、RFID、立项 |
| `#业务/组织` | 组织 / 人员 / 任职 | 履职报告、任职资格 |
| `#业务/项目` | 项目立项 / 成果 | RFID、智能体、国际化 |
| `#业务/元数据` | 知识库整理 / 目录 | 整理报告、目录、导出记录 |

## 二级主题（必选 ≥1 个）

- `#主题/流程` — 工作流程、模板、检查单
- `#主题/规范` — 制度、规范、标准
- `#主题/案例` — 实际案例、复盘
- `#主题/培训` — 培训材料
- `#主题/技术` — 技术方案、架构
- `#主题/管理` — 管理、履职、组织

## 三级来源 / 状态（可选）

- `#来源/ima` — 来自 ima 知识库（待同步后标记）
- `#来源/本地` — 本地原产
- `#状态/现行` — 当前生效
- `#状态/历史` — 历史版本
- `#状态/待审` — 待审核
- `#状态/已废` — 已废止

## 四级地区（外战专用）

- `#地区/华东` / `#地区/华北` / `#地区/华南` / `#地区/华中` / `#地区/西南` / `#地区/西北` / `#地区/东北`

## tag 决策规则

参考 `~/.mavis/agents/mavis/memory/openclaw-workspace.md` 中的 `alias_decision_rules`：

- **R1 必选类别**：每个文件至少 1 个一级类别 tag
- **R2 主题必填**：每个文件至少 1 个二级主题 tag
- **R3 状态可选**：现行/历史/待审/已废，只在明确时打
- **R4 来源必填**：明确 ima 同步 / 本地原产
- **R5 外战加地区**：外战保障预案必须加 `#地区/*`
- **R6 改名不丢 tag**：文件改名时 tag 体系不变
- **R7 RAW 永不动**：所有整理在 `AOG知识库/` 内, `AOG智能体/RAW/` 保持原版
- **R8 整理在 AOG知识库/**：7 主题子目录 `01-07_*` + wiki 元件 `_xxx.md` + MOC `00_MOC/`
- **R9 命名约定**：素材层数字编号 (`01-07`), 元件层下划线前缀 (`_xxx.md`)
