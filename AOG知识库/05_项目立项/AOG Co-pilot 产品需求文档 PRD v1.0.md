AOG Co-pilot 产品需求文档 PRD v1.0文档状态：v1.0 需求确认版产品定位：面向航材 AOG 保障人员和管理者的本地化智能保障工作平台部署方式：局域网私有部署，Mac mini 或任意本地电脑作为服务器核心验收场景：B-30EP 雷达罩 AOG1. 产品目标AOG Co-pilot 是一个以 AOG 保障任务为核心的智能工作平台，帮助保障人员完成任务录入、方案生成、动态检查单执行、状态监控、通报草稿、表格填充、案例复盘和知识沉淀。产品目标不是让 AI 自动替人决策，而是：更快录入 AOG 需求更快生成保障方案和通报减少检查单漏项实时监控保障进度和风险沉淀保障经验、预案和案例通过长期记忆、向量检索和知识图谱持续提升 AI 搜索与建议准确率2. 用户角色角色权限管理员用户、部门、模板、知识库、系统配置、备份恢复管理者查看全部任务、审批复盘、确认知识库写入、查看看板保障人员创建/执行任务、更新检查单、生成通报/表格、上传附件只读用户查看任务、看板、知识库外部协作仅查看或更新被授权的任务节点权限需支持部门/处室维度。3. 信息架构一级导航收敛为 5 个：工作台AOG 任务知识管理用户权限系统设置模块归属：动态检查单：AOG 任务详情内地图看板：AOG 任务的地图/时间视图航班/时间监控：任务监控视图内案例复盘：知识管理内报告/邮件/表格模板：知识管理内4. 工作台工作台是默认首页，定位为 AOG 保障监控看板。第一屏必须展示：当前进行中的 AOG 任务航材当前位置预计到达时间 ETAAOG 等级与状态AI 智能对话入口工作台偏“动态监控”，不承担完整任务编辑职责。5. AOG 任务5.1 默认视图AOG 任务页默认采用：列表视图 + 风险置顶可切换：看板视图：按状态分组地图/时间视图：航站、运输路径、ETA、倒计时5.2 创建方式任务创建以自然语言和文件导入为主，表单为补录与确认。支持：自然语言录入Excel/邮件/PDF/图片导入手动补录创建前必须进入字段确认页，用户确认后才生成任务。5.3 自动识别字段系统从文本中自动提取字段，并显示置信度：高：直接填入中：黄色提示，建议确认低：留空或红色提示必填字段：AOG 等级机号机型地点/航站故障信息需求时间下个航班日期/时间件号件名数量责任人，默认录入人航班号备注6. AOG 等级与风险AOG 保障等级支持手动选择、AI 建议、管理员配置。等级定义默认颜色1级洲际 AOG，欧洲/澳洲红色2级国际 AOG、计划执行洲际航线 787 AOG、虹浦两场短时调配橙色3级国内外站短停 AOG黄色4级其他 AOG蓝色未定级信息缺失灰色风险主色按 AOG 等级，不用简单 ETA 阈值替代业务等级。附加告警包括：检查单关键节点超时检查项未留痕保障方案长期未更新关键字段缺失通报节点未完成7. 任务状态主状态：新建 → 需求确认中 → 方案制定中 → 保障执行中 → 运输中 → 到件待交付 → 已交付 → 复盘中 → 关闭异常状态：阻塞超时风险取消挂起8. 任务详情页采用三栏结构：左侧：基础信息状态AOG 等级责任人部门/处室中间：当前保障方案方案历史版本动态检查单时间线沟通记录附件右侧：任务 AI 助手知识推荐邮件/通报生成Excel 填充复盘草稿生成9. 动态检查单所有任务先套用AOG保障检查单模板R1.xlsx，再根据条件追加节点。基础流程包括：确认需求确认航材保障方案确认运输方案出库/提货运输节点到达/交付收尾/复盘条件节点：条件自动追加国际/洲际报关、运输、备份方案危险品/化工品危险品运输检查时控件证书/寿命检查OBC 手提人员、航班、行李限制上海虹浦调配两场调拨节点每个检查项必须记录：完成状态负责人时间可选记录：备注附件证据截图/文件AI 建议人工可新增、删除、排序检查项，但必须保留变更记录。10. 保障方案版本AOG 过程中保障方案允许持续更新。每次变更必须记录：当前方案历史版本变更原因变更人变更时间AI 对新旧方案的差异总结AI 不能自动覆盖人工方案，只能提出建议。11. 通报与模板MVP 只生成草稿，不自动发送。模板类型：AOG 通报模板方案确认邮件运输节点通报邮件到件/交付通知异常升级通报复盘报告AOG 检查单 Excel通报节点：收到需求30 分钟节点方案确认出库提货发车/起飞到达目的地交付异常升级复盘关闭未来预留：邮件企业微信飞书短信交联系统 API12. 地图与时间监控MVP 使用离线地图：离线世界/中国 GeoJSONECharts 地图航站/城市/国家经纬度内置表 + 人工维护人工更新航材当前位置人工选择起点/终点生成运输路径展示：当前 AOG 任务数量风险等级颜色航站/城市/国家航材运输路径航材当前位置ETA剩余保障时间航班/物流动态 API 暂不接入，后续通过 Provider 适配。可评估 FlightAware AeroAPI、Cirium、Aviationstack、VariFlight 等商业数据源。13. AI 能力边界AI 可以：查询知识库自动提取字段显示字段置信度推荐 AOG 等级生成保障方案生成通报/邮件/Excel提醒下一步动作生成复盘草稿AI 不可以：自动关闭任务自动外发邮件/消息自动修改正式知识库自动覆盖人工方案自动提交外部系统自动修改正式检查单模板所有关键动作必须人工确认。14. AI 入口系统提供三个 AI 入口：工作台全局 AI回答全局任务、流程、知识、状态问题。AOG 任务 AI带当前任务上下文，生成方案、通报、表格、复盘。知识管理 AI查询预案、经验、案例、件号、互换件、供应商、模板。15. 知识管理知识库按 Obsidian 方法组织，目标是人和 AI 都能读。目录结构：00_AOG知识总览
01_保障预案
02_保障经验
03_AOG案例复盘
04_规章手册协议
05_供应商航司互援资源
06_运输报关危险品
07_件号保障经验
08_检查单模板与规则
09_邮件表格报告模板
10_AI记忆与优化
每个原始文件保留，生成 Markdown sidecar。必须支持：MarkdownTXTPDFWordExcelXMind图片 OCR 基础支持音频/视频先建索引和待处理状态知识文件必须包含 YAML 元数据、MOC、标签、双向链接。16. 向量嵌入与知识图谱知识库采用三层架构：Obsidian 知识层Markdown、YAML、MOC、双链。向量嵌入层对 sidecar、文档提取文本、案例、方案、检查单经验分块 embedding。知识图谱层建立任务、飞机、机型、航站、国家、件号、供应商、运输方式、AOG 等级、案例、预案、检查项、模板、部门之间的关系。AI 查询采用混合检索：当前任务上下文知识图谱强关联向量语义搜索元数据过滤引用来源输出知识健康度需展示：未嵌入文档无标签文档孤岛节点重复知识过期知识检索失败记录17. AI 长期记忆AI 记忆分为五层：会话记忆任务事实记忆知识库记忆复盘学习记忆系统优化记忆记忆状态：draftproposedapproveddeprecatedrejectedAI 可以提出记忆，不得直接写入正式知识库。AOG 完成后必须触发复盘流程：任务时间线 → 方案对比 → 风险识别 → 成功经验 → 失败教训 → 知识库更新建议 → 管理者审批 → 写入正式知识库。18. 案例复盘复盘内容包括：过程记录时间线问题与风险成功经验失败教训可复用预案更新建议下次 checklist 优化建议复盘草稿由 AI 生成，管理者审批后才能进入正式案例库。19. 协同与锁定MVP 支持局域网多端协同。同一任务编辑规则：同时只能 1 人编辑其他人只读查看锁定 15 分钟无操作自动释放管理员可强制解锁所有编辑写入操作日志20. 审计日志必须审计：创建/修改任务修改方案完成检查项生成/确认通报上传/删除附件复盘审批写入知识库用户权限变更管理员强制解锁21. 技术架构建议aog-copilot/
